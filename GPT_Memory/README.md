# GPT Memory Pack（跨帳號 AI 記憶包）

- **目的：** 讓不同 ChatGPT 帳號或其他 AI 助手透過公開 GitHub 文件重建必要的 YSOS 工作脈絡與治理規則。
- **語言：** 繁體中文為主，保留必要英文術語。
- **狀態：** Portable reference pack（可移植參考包）；不是模型內部記憶的完整複製品。
- **權威來源：** 本目錄中的版本化文件。若其他對話或模型記憶與此處衝突，應標示衝突並請人類決策者仲裁，不得靜默覆寫。

## 建議讀取順序

1. [CORE_MEMORY.md](CORE_MEMORY.md) — YSOS 核心概念與工作背景。
2. [GOVERNANCE_RULES.md](GOVERNANCE_RULES.md) — 證據、授權、版本與施工邊界。
3. [GRILL_ME_MODE_M46_SPEC.md](GRILL_ME_MODE_M46_SPEC.md) — M46 反詰澄清模式詳細規格。
4. [AI_ACCOUNT_BOOTSTRAP.md](AI_ACCOUNT_BOOTSTRAP.md) — 新帳號／新模型的載入指示。
5. [MEMORY_CHANGELOG.md](MEMORY_CHANGELOG.md) — 版本與變更紀錄。

## 給 AI 助手的使用規則

- 開始工作前，先讀取以上文件，並簡短回報實際讀取到的文件及其版本／狀態。
- 區分已確認事實、直接觀測證據、推論、建議、未知、衝突及待人類決策事項。
- 不得把文件存在視為功能已實作、治理已執行、測試已通過或模式已啟用。
- 不得把可選建議自動納入使用者需求。
- 討論、分析、規劃、審核不自動等於施工授權。
- 若公開文件不足以支持某項主張，明確標示資訊不足，不得自行補造。
- 重要更新應提出 diff／PR，保留可追溯的版本紀錄。

## 公開資料注意事項

本目錄設計為公開、可供其他 AI 讀取的參考資料。不得在此提交密碼、API keys、access tokens、個人識別資料、私人對話原文、健康資料、私有 Repo 連結或未經授權公開的專案細節。公開前應檢查每次變更的 diff。

## 重要限制

讀取這些文件只能提供外部工作脈絡，無法複製另一 ChatGPT 帳號的內部 Memory、帳號設定、完整聊天歷史或工具權限。每個模型／帳號仍需依自身能力與可用工具執行任務。
